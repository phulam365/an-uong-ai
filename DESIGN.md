# Homepage Menu Design

## Direction

The homepage is a compact public menu inspired by fast delivery interfaces. It should show useful browsing controls immediately, avoid brand copying, and use original food photography-style assets.

## Palette

- Yellow: active surfaces, page energy, selected category accents.
- Red: primary actions, price accents, modal controls.
- White: cards, content surfaces, and readable space.
- Charcoal: text and button contrast.

## Layout

- Desktop uses a sticky left category rail and a right product grid.
- Mobile uses horizontal category tabs above a one or two column grid.
- Product cards stay compact with stable image areas, concise copy, price, and quantity controls.

## Interaction

- Quantity state is local to the React page.
- Detail opens from the product card or view action.
- Detail closes from backdrop click, close button, and Escape.
